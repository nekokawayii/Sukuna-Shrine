# Sukuna Shrine · 宿傩 · 伏魔御厨子

《咒术回战》题材的 Minecraft **Forge 1.20.1** 战斗与成长模组。以两面宿傩为核心，包含六种基础术式的全部成长阶段（觉醒 / 九相 / 灵魂 / 虚空 / 净土传承）、**伏魔御厨子**与**无量空处**两套领域、领域对拼、多个首领与专属维度、女仆联动，以及完整的特效、音效与配置系统。

当前版本：**1.6.0-r214**（版本号形如 `1.6.0-rNNN`，每个 rNNN 都是一次可回档的发布）

> 完整的游戏内机制、数值、按键与首领攻略见 **[使用说明.md](使用说明.md)**（700+ 行手册，本文只做门面与上手说明）。

---

## 一、环境要求

| 项 | 说明 |
|---|---|
| 游戏 | Minecraft **1.20.1** |
| 加载器 | Minecraft Forge **47.x** |
| 必需前置 | 无 |
| 可选前置 | **Photon**（程序化特效 1.1.17）、**PlayerAnimator**（骨骼动画 1.0.2-rc1+1.20）、**TLM 女仆模组**（女仆施法者） |

可选前置**不装也能跑**：特效降级为内置表现、玩家动作用模组自绘的关键帧动作组（8 段：后翻／飞踢／滑铲／冲拳／跪地／砸地／旋转／简易领域）、女仆相关技能不可用。

---

## 二、安装

1. 把 jar 放进 `.minecraft/mods/`；
2. 本仓库产物有**两个变体**，**同一 modid 只能放一份**：

| 变体 | 差异 |
|---|---|
| `-auto-share` | 斩击壁纸分享**默认开启** |
| `-ask` | 每次询问是否分享壁纸 |

3. 多人服务器要求客户端与所有玩家使用**同一版本**。

## 三、上手与按键

- **选择技能**：长按 **N** 打开轮盘 → 鼠标选择 → 松手确定；按 **R** 释放；按 **J** 查看任务。
- 六眼（五条悟）、里梅冰系是**各自的独立圆环**，与宿傩轮盘互不覆盖。
- 释放键分三态：按下（`phase 0`）、按住心跳（`phase 1`）、松手（`phase 2`）——长按类技能靠心跳维持。

### 3.1 解动作（按方向键组合触发）

| 按键组合 | 动作 |
|---|---|
| 蹲下 + 前进 | 飞踢 |
| 蹲下 + 后退／后退 + 跳 | 后翻 |
| 蹲下 + 不动 | 跪地 |
| **疾跑 + 前进** | 滑铲 |
| **疾跑 + 前进 + 跳**（或上升中） | 冲拳（空中也可触发） |
| 都不满足 | 走普通「解」 |

> 动作**不需要先蹲下**（蹲下就疾跑不了，滑铲会永远用不出来）。动作期间切到背后第三人称，收招后恢复原视角。

### 3.2 领域：伏魔御厨子（技能 5）

| 手续 | 行为 |
|---|---|
| 第 1 次按 | **结印**：3 秒不能移动 + 双手解印 |
| 第 4 秒 | **领域出现**（半径 200 格），之后可移动，但**保持结印** |
| 结印期间 | 不能释放其它术式、不能攻击 |
| 第 2 次按 | **放下**：姿态解除，领域保留，**御厨子伤害降为 50%** |
| 第 3 次按 | **收起**领域 |
| 冷却 | 领域结束后 **30 秒**（只锁领域本身） |

展开后**任何时候连按三次空格**，会沿曲线飞到神龛上站住。

### 3.3 领域：无量空处（五条悟）

| 手续 | 行为 |
|---|---|
| 第 1 次按 | **结印**：3 秒不能移动 + **单手竖在屏幕正中央**解印 |
| 第 4 秒 | 领域出现，可移动但仍保持结印 |
| 第 2 次按 | **放下**：此后**无伤害、仅控制**（拴点／缓慢等控制保留） |
| 第 3 次按 | 收起领域 |

展开时依次播放两段专属音效（起手段 → 无缝衔接段）。

### 3.4 标志性技能速查

| 技能 | 要点 |
|---|---|
| 解 · 剑气模式／斩击模式 | 基础远程斩击，模式可在轮盘顶部切换 |
| 捌 · 必断斩击 | 短按开关、长按 0.7 秒释放必断 |
| 开／灶／灶·开 | 炎弓、粉尘爆炸与二者合流 |
| 简易领域 · 捌 | 半径 5 圆柱领域，维持每秒 150 咒力，期间移速 ×0.3、两手上举 |
| 灶 · 最大功率 · 开 | 长按蓄力 20 秒（无法移动、FOV ×2、周身敌人燃烧），满 20 秒自动击发：弓矢命中造成半径 100 格爆炸并冻结 15 秒；对魔虚罗额外固定 100000 伤害 |
| 世界斩／龙之昴星／终式·六道连斩 | 高阶段招式，各有咏唱与熔断代价 |
| 神武解 | 手持时禁用术式，按住释放键充能、再右键打出扇形雷击 |
| 魔虚罗 · 法轮 | 受击累积适应（减伤→免疫），召唤物与主人共享适应表 |

## 四、构建

```bash
./gradlew build --console=plain -Dnet.minecraftforge.gradle.check.certs=false --offline
```

- `--offline` 是**必需**的（在线校验会因证书问题间歇失败）；
- 产物：`build/libs/sukuna-forge-1.20.1-<版本>-{auto-share,ask}.jar`；
- 构建脚本会把产物自动同步到本机约定位置（桌面「打包」目录与测试整合包的 `mods/`），并只保留一份可加载的 sukuna jar；
- 前置 jar（PlayerAnimator、TLM 等）以 `compileOnly` 方式放在 `libs/`，**不打包进产物**。

## 五、版本与回档

每次发版都会：

1. `git commit` + `git push` 留档；
2. 建立 **GitHub Release**，tag 为 `v<版本号>`，附件为 `-auto-share` 与 `-ask` 两个 jar（脚本见 `scripts/release.sh`）。

需要回档时，取对应 Release 的 jar 丢进 `mods/` 即可（记得先删掉其它版本的 sukuna jar）。

## 六、已知限制

- **同一 modid 只能放一份 jar**：`-auto-share` 与 `-ask` 不能同时放，否则 Forge 会报重复模组或只加载其一。
- **可选前置缺失时表现降级**，但不影响技能逻辑与伤害结算。
- 技能伤害与判定**在服务端结算**，客户端表现偶发不同步时以服务端为准。
- 斩击壁纸（斩击内部显示本机桌面）只在**本机**生效、不上传分享；窗口模式最稳定，全屏下需周期性最小化窗口抓取。
- 动作／领域期间的数值与手感仍在持续调整，版本号变更较快。
