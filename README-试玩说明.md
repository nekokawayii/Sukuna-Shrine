## 一、这是什么

Minecraft **1.20.1 + Forge 47.4.x** 模组「宿傩 · 伏魔御厨子」（modid `sukuna`，仓库 `nekokawayii/Sukuna-Shrine`）的按版本交付说明集。

题材：两面宿傩（解/捌/伏魔御厨子/领域展开）、五条悟（六眼九式/无量空处）、里梅冰凝咒法、魔虚罗与法轮、即身佛、咒具神武解与飞天、伏黑惠与十种影法术、赤血操术，以及一条四阶段的隐藏剧情「观测者」。

前置：客户端需要 **Photon 1.1.17**；女仆联动需要车万女仆；动作已由模组自绘，不再强制 PlayerAnimator。

## 二、安装与排错（所有版本通用）

1. **先备份存档**，完全退出游戏再换 jar。
2. `mods` 里**只放一份** sukuna（`-ask` 与 `-auto-share` 是同一个模组，二选一）。
3. **联机时服务端与所有客户端同版本**，旧版网络协议会被拒绝连接。
4. 新增维度（牢房等）需要**重新进入世界**，不要只用 `/reload`。
5. 高位版紧急手段：**F8** 恢复窗口并停用本局桌面特效、**Esc** 退出、**F7** 切换原生弹窗。
6. 报错请附：`crash-reports/` 最新 `crash-*.txt` + `logs/latest.log`；动作难看请录第三人称短视频；模型异常请说明式神名。

> ⚠️ **文件名编号 ≠ 成品版本号**：r109 说明是 r110 成品、r113→r114、r78→r79、r89→r90、r91→r94、r41→r43。以正文“成品 rXX”为准。
