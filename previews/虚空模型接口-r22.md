# 虚空模型接口 r22

目标：Minecraft Java 1.20.1 Forge。游戏使用现有 `BbModel` 读取器直接加载原生 `.bbmodel`，无需另装模型依赖。贴图均为128×128，嵌入模型的贴图与游戏外部PNG相同。坐标每16单位为一格，Y轴向上、正面朝-Z。

## 聚合体

可编辑合体版：`虚空聚合体-r22.bbmodel`。游戏中分别读取 `void_aggregate.bbmodel` 与 `void_core.bbmodel`，主体正常受光，核心全亮。

静态尺寸：72×86×31单位，约4.5×5.375×1.94格，脚底Y=0。实体碰撞箱宽4.5、高5.4格。

| 骨骼 | 父骨骼 | 轴心 |
| --- | --- | --- |
| root | 无 | (0,40,0) |
| shell_left / shell_right | root | (-13,49,0) / (13,49,0) |
| arm_left / arm_right | root | (-27,61,0) / (27,61,0) |
| leg_left / leg_right | root | (-8,27,0) / (8,27,0) |
| core | 合体版为root，游戏独立核心为根骨骼 | (0,47,-3) |

动画：`idle` 3秒循环；`cast` 1.5秒循环；`open` 2秒循环。独立核心 `spin` 4秒循环，合体可编辑版对应 `core_spin`。完整360°旋转末帧虽然数值为360°，方向与首帧0°等价。

游戏施法时使用 `cast`，虚空终焉与虚空降临使用 `open`。游戏核心动画与主体动画同步播放，编辑器中的合体版本可分别选择动作查看。

## 虚空神龛

文件：`../src/main/resources/assets/sukuna/models/void_shrine.bbmodel`。
尺寸：191.5×144×191.5单位，约12×9×12格，地台底部Y=0。

- `root`，轴心(0,0,0)。
- `heart`，父骨骼root，轴心(0,54,0)。
- `bell_-78_-78`、`bell_-78_78`、`bell_78_-78`、`bell_78_78`，均为root子骨骼，轴心分别为(x,92,z)。
- `awaken`，8秒循环：四个铃铛绕Y轴旋转，核心反向旋转。

四眼虚影、紫色暗芒、祭坛咒纹、放射地裂和残影由游戏效果渲染补充。模型预览只展示实体几何、贴图和骨骼动画。
